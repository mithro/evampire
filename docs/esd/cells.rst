gf180mcu I/O cells
==================

Every pad cell of the gf180mcu I/O library has ESD protection built in,
which its netlist lists and its mask layout shows.

:doc:`io-cells`
   The protection inside the gf180mcu I/O cells, and the limits of each
   device as the foundry measured them.
:doc:`layout`
   The same protection in the cells' mask layouts, drawn from the
   foundry's GDS files and checked against the netlists.
